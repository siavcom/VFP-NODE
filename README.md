VFP-NODE
Back-End server for web-ones technology https://github.com/siavcom/web-ones-technology


Clone this project in sonme directory

To install :
 npm install

You have to download jasperstarter(https://sourceforge.net/projects/jasperstarter/) and extract it in a main directory

DB connection configuration files is in :

	app/empresas/<configuartion folder>
	 in this folder you have db.config.js configuration file

example in : app/empresas/web-ones/db.config.js

run :
  node server_sockets.js
